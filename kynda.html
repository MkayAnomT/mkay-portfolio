01 · Overview

Learning, made more accessible.

Kynda is an educational product concept created as a team project. The goal was to shape a digital learning experience that feels clear, approachable and easy to navigate rather than overwhelming the learner with unnecessary complexity.

My contribution focused on frontend implementation, translating the team's product direction and UI decisions into responsive web screens using HTML, CSS and JavaScript.

04 · My contribution

Design direction into working UI.

01

Understand

Review the team's product direction, interface requirements and the learner journey the experience needed to support.

02

Translate

Break the visual direction into reusable page structures, responsive layouts and implementation-ready interface details.

03

Build

Implement the interface with HTML, CSS and JavaScript, paying attention to spacing, typography, components, interactions and responsive behavior.

04

Refine

Compare the implementation against the intended UI and refine details where the coded experience differs from the design.

05 · What I learned

Good teamwork changes how you build.

Kynda gave me experience working within an existing product direction rather than treating every design decision as an individual one.

01
Design and development need a shared language.

Clear spacing, component and interaction decisions make the transition from design to frontend much smoother.

02
Consistency matters across a team.

A shared visual system helps different contributors produce interfaces that still feel like one product.

03
Implementation reveals design gaps.

Building the UI exposes edge cases and responsive behavior that are easy to miss in static screens.

04
My frontend role strengthened my product thinking.

Working closer to implementation made it easier to consider what is practical, responsive and maintainable.
